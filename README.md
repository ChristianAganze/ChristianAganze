# Salut, je suis Christian Aganze ! 👋 📱

**Développeur Mobile chez DrcMind & Futur Ingénieur en Système Informatique**

Je suis actuellement étudiant finaliste en **Système Informatique** à l'**Université Catholique de Bukavu (UCB)** et développeur au sein de l'équipe **DrcMind**.
